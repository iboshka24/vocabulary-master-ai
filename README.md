# Vocabulary Master AI

Слово за словом. Каждый день.

Версия 2.0 собственного проекта [WordLoop](https://github.com/iboshka24/vocabulary-master-ai): сохранены API-интеграции, парсер, озвучка и бесконечная очередь повторений. Новый интерфейс — бумага, чернила, янтарь, выразительная типографика. Без неонового фона, частиц и параллакса.

## Возможности

- **Язык интерфейса: Русский / English / O‘zbekcha** — переключатель 🌐 в шапке. Выбор запоминается; при первом входе язык берётся из браузера. Все тексты лежат в `i18n.js` (`[ru, en, uz]` на ключ), тест `test/i18n.js` проверяет, что ни одного ключа не пропущено.
- 20 языков, отдельные селекторы изучаемого и родного языка.
- Ввод списков и готовых пар: `apple - яблоко`. Удаление дубликатов и мусорных строк.
- ИИ-перевод, мнемоника, определение и примеры через OpenAI-совместимый API.
- Без ключа: небольшой встроенный EN↔RU-словарь и MyMemory с кэшем. Это машинный перевод, **не генеративный ИИ**. Если перевод недоступен, его можно исправить в библиотеке.
- Карточки и письменный ответ, прямое / обратное / смешанное направление. Правильный ответ виден после попытки; забытые слова возвращаются в текущую очередь.
- **Свап языков ⇄** (кнопка между селекторами или `Alt+X`): изучаемый и родной язык меняются местами, а готовые пары в списке разворачиваются (`apple - яблоко` → `яблоко - apple`). Если выбрать одинаковый язык с обеих сторон, языки тоже просто поменяются.
- **Интервальные повторения SM-2** (v2.7): после переворота — «Не вспомнил» (1), «Трудно» (3), «Запомнил» (2), «Легко» (4). Интервалы 1 → 6 → интервал × лёгкость, «трудно» ×1.2, «легко» ×лёгкость×1.3, лёгкость не ниже 1.3, ошибка возвращает слово через 10 минут и начинает заново с 1 дня. В режиме ввода верный ответ после подсказки считается «трудно». Старый прогресс (ступени 0–5) переносится автоматически. Расписание покрыто тестами в `test/learning.js`.
- **Офлайн-синхронизация**: слова, добавленные без сети, получают «—»; при возвращении интернета (и при следующем запуске) переводы догружаются сами, не больше 30 за раз.
- **Доступность**: контраст текста в светлой теме ≥ 4.5:1 (WCAG AA), карточка — кнопка с понятной aria-меткой, ответ объявляется скринридеру, заметный фокус, состояние плиток в игре через `aria-pressed`. 3D-анимации выключены при `prefers-reduced-motion`, а также по умолчанию на слабых телефонах (≤2 ГБ памяти, ≤2 ядра, режим экономии трафика) — кнопка «3D» включает их вручную.
- **Производительность** (Lighthouse, мобильный профиль, локально): 52 → 86. lottie (~170 КБ) грузится только когда начинается тренировка, скрипты с `defer`, Google Fonts не блокируют отрисовку, мелкий текст ≥ 12px.
- Ступени SRS и дата следующего повторения сохраняются. «Повторить» запускает слова, срок которых подошёл (если таких нет — всю колоду); «Сложные» — только слова с ошибками, самые трудные первыми.
- **⇄ Развернуть языки** в колоде создаёт обратную колоду (например, Русский → English) с нулевым прогрессом; повторный разворот добавляет только новые слова. «Скопировать списком» копирует колоду как `слово - перевод`.
- **🎧 На слух** — третий режим ответа: слово произносится вслух (Web Speech API), его нужно написать. Следующая карточка в стопке тоже скрыта, чтобы не подсмотреть. Нужен включённый звук.
- **↶ Отменить** (`U` или кнопка) — откатывает последний ответ: прогресс SRS слова, счётчики сессии и дневную статистику; карточка возвращается на экран.
- **Найди пару** (вкладка «Лексический тест») — 6 слов и 6 переводов вперемешку, соедини на время. Рекорд хранится для каждой колоды; законченная игра засчитывается в серию дней.
- **За подход: все / 10 / 20 / 30** в библиотеке — короткая сессия берёт самые просроченные (или самые трудные) слова, а «Повторить всё» — случайные.
- **Приложение и офлайн (PWA)** — `manifest.webmanifest`, иконки и `sw.js`: сайт можно установить на телефон/компьютер (кнопка ⤓ появляется в шапке, когда браузер это разрешает) и открыть без интернета. Сначала всегда сеть, кэш — только запасной вариант, поэтому обновления приходят сразу; `/api/` и внешние переводчики не кэшируются. Иконки пересобираются командой `node tools/make-icons.js`.
- **Подсказка 💡** (`H` или кнопка): первые буквы ответа, каждое нажатие открывает ещё одну букву.
- **Поиск** по всем колодам библиотеки и **календарь активности** за 12 недель (интенсивность относительно дневной цели).
- Несколько колод по языковой паре, просмотр, исправление и удаление слов. Резервная копия библиотеки в JSON — без API-ключей.
- Lexical Resource: мини-тест из пользовательских слов, четыре разных варианта. При наличии примера — пропуск в предложении; иначе вопрос на значение. Это учебный режим, **не официальная оценка SAT/IELTS**.
- Дневная цель, история ответов, серия дней. Серия засчитывается при завершении тренировки с ответами или всего мини-теста. Streak Freeze: две начальные защиты, одна на пропущенный день; повторная загрузка не списывает защиту повторно. Автоматического пополнения нет.
- Светлая и тёмная темы, мобильная вёрстка, поддержка `prefers-reduced-motion`.
- Озвучка Web Speech API: доступные голоса зависят от устройства.

## Запуск

Нужен Node.js 18+; для браузерных тестов — Node.js 20+.

```sh
git clone https://github.com/iboshka24/vocabulary-master-ai.git
cd vocabulary-master-ai
npm install
npm run dev
```

Открыть http://localhost:3000. Сборки нет: HTML, CSS и обычный JavaScript. `index.html` можно открыть напрямую; для полноценной работы API рекомендуется HTTP/Vercel. Демо и готовые пары работают без сети. Google Fonts, перевод и LLM требуют сети; серверный прокси не запускается командой `npm run dev`.

## Настройка ИИ

На Vercel импортировать репозиторий и задать переменные окружения:

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | Серверный ключ |
| `OPENAI_BASE_URL` | По умолчанию `https://api.openai.com/v1` |
| `OPENAI_MODEL` | По умолчанию `gpt-4o-mini` |

Поддерживаются OpenAI-совместимые провайдеры, включая Groq, OpenRouter и DeepSeek. При серверном ключе адрес и модель берутся **только из окружения**, не из запроса. HTTP и перенаправления запрещены. При публичном размещении добавьте ограничения доступа / rate limiting на стороне платформы: встроенного биллинга и пользовательских аккаунтов нет.

Альтернатива — собственный ключ в разделе «API / модель». Он хранится в `localStorage` этого браузера. Не вводите личный ключ на чужом устройстве; для публичного сайта предпочтительнее серверная настройка. Прямые браузерные запросы также зависят от CORS провайдера.

**Приватность:** обучение и прогресс сохраняются локально; слова, требующие перевода, отправляются выбранному сервису. Это не полностью офлайн-приложение. Очистка данных браузера удалит прогресс — скачивайте резервные копии. Существующие ключи `wordloop.cfg`, `wordloop.session` сохранены для совместимости; библиотека v2 использует отдельный ключ.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:browser
```

Тесты проверяют парсер, API, очередь, гонки переходов, ввод ответа, SRS, защиту серии и разные варианты теста. Реальный Chromium проверяет карточки, ввод, библиотеку, тест, сохранение, темы и мобильную ширину. Скриншоты пишутся в системную временную папку; путь можно задать через `VM_SCREENSHOTS`.

## Motion: вручную и EffectCraft

### v2.3 — бесшовный swap и настоящие свайпы

Следующая карточка заранее содержит **реальное следующее слово**, включая выбранное направление Mixed. Старая карточка уходит вправо/влево, следующая одновременно поднимается из стопки за 480 мс. После движения интерактивная карточка принимает её содержимое без повторного fade-in и пустого кадра. Переход между раундами использует ту же заранее подготовленную очередь. Переворот сокращён до 640 мс; быстрый ответ дожидается его завершения.

На открытой карточке работают жесты мышью и touch: вправо — «знаю», влево — «повторить». Короткий или отменённый жест возвращает карточку без оценки. Вертикальная прокрутка не перехватывается; кнопки и клавиатура остаются доступны. В режиме письменного ответа свайп-оценка отключена.

Для swap анимируются только `transform`/`opacity`, используются два постоянных слоя без клонирования DOM на каждый ответ. Убраны прежние принудительные reflow и создание скрытых частиц. Координаты жестов обновляются один раз за кадр через rAF; геометрия считывается при начале жеста, а не на каждом движении. `will-change` действует только во время перехода. Это меры оптимизации, не обещание фиксированного FPS на любом устройстве.

Chromium-проверки: одновременное движение двух карточек, совпадение preview и следующего слова (включая новый раунд), отсутствие повторного fade-in, свайпы мышью в обе стороны, отмена короткого жеста, мобильный touch через CDP, reduced motion. На физических телефонах и в Safari/Firefox отдельно не проверялось.

### v2.2 — настоящая хореография колоды

- На главной раскрывается веер карточек, затем пример делает полный 3D-переворот туда и обратно. Нажатие позволяет повторить его; автоматическая демонстрация конечная.
- В тренировке три отдельных уровня: движение всей карточки, наклон за мышью и вращение лицевой/оборотной стороны. Полный переворот занимает 920 мс с небольшим перелётом и возвращением.
- Нажатие на карточку или пробел переворачивает её в обе стороны, без автоматической оценки. Enter после раскрытия сохраняет прежнее действие «запомнил».
- Стопка видна под активной карточкой. Знакомое слово уходит по дуге вверх, забытое — под колоду; следующая карточка подаётся с глубины.
- Исправлено обрезание анимации прежним таймером 180 мс. Даже при быстром нажатии ответа сначала завершается переворот, затем уход; оборот не сбрасывается посреди движения.
- Кнопка **3D** в шапке явно включает/выключает motion и запоминает выбор. По умолчанию соблюдается системное reduced motion; включение кнопкой позволяет пользователю сознательно выбрать полное движение.
- Браузерные проверки измеряют промежуточные 3D-матрицы поворота и наклона, проверяют, что ответ не заменён до завершения движения, и сохраняют кадры поворота/ухода.

### v2.1 — motion в самом приложении

`motion.js` + `motion.css` задают последовательное появление заголовков, вход блоков при прокрутке, короткие переходы экранов, разный уход известных/забытых карточек, отклик письменных ответов, hover/press и движение прогресса. Анимации конечные, не блокируют ввод и отменяются при смене экрана. Нет фоновых частиц или бесконечного параллакса.

**Новая композиция `EditorialAchievement` создана в EffectCraft CLI** по workflow репозитория [iboshka24/effectcraft-mcp](https://github.com/iboshka24/effectcraft-mcp), затем экспортирована в Lottie: 320×240, прозрачный фон, 2.4 секунды, 15 shape-слоёв, без экспортных предупреждений. Стопка бумажных карточек, янтарная закладка и зелёная печать появляются **в итогах тренировки и при достижении дневной цели**, а не только в отдельном примере.

Плеер `lottie-web` 5.13.0 лежит локально в `vendor/` вместе с MIT-лицензией. JSON обёрнут в обычный JS для работы с `file://`. CDN и сетевые запросы для motion не нужны. При `prefers-reduced-motion` показывается последний статичный кадр; изменение настройки применяется сразу. В фоновой вкладке движение останавливается.

Пересборка новой композиции:

```powershell
powershell -ExecutionPolicy Bypass -File tools\effectcraft\build-editorial.ps1 -CliPath "C:\path\effectcraft-cli.exe"
```

Исходник: `tools/effectcraft/editorial-achievement.jsx`, редактируемый проект: `tools/effectcraft/build/editorial-achievement.ecproj`, экспорт: `motion/editorial-achievement.json` и `.js`. Скопированный плеер обновляется из `node_modules/lottie-web/build/player/lottie_light.min.js` после обновления зависимости.

### Предыдущий сравнительный этюд

В библиотеке раздел «За кулисами» позволяет сравнить простую CSS-анимацию с **реальным MP4-рендером EffectCraft**. Рендер — отдельный motion-этюд из первой версии, намеренно не используемый как оформление сайта. Видео включается вручную, без автопроигрывания.

- `motion/streak-celebration.mp4` — готовый рендер.
- `motion/streak-celebration.json` — Lottie-экспорт.
- `tools/effectcraft/streak-celebration.jsx` — исходный генератор композиции.
- `tools/effectcraft/build/streak-celebration.ecproj` — редактируемый проект.

Для пересборки нужен EffectCraft CLI v0.10.0:

```powershell
powershell -ExecutionPolicy Bypass -File tools\effectcraft\build-motion.ps1 -CliPath "C:\path\effectcraft-cli.exe"
```

Скрипт также генерирует GIF, PNG и JS-обёртку Lottie. Бинарник EffectCraft не включён в репозиторий.
