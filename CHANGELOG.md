# Изменения

Версии v2.4–v2.6 уже в `main`. Ниже — то, что лежит на ветке `feat/sm2-a11y-perf` и ещё не опубликовано (v2.7–v2.10).

## v2.10 — отмена действий, пустые состояния, покрытие тестами

**Для пользователя**
- После удаления колоды, удаления слова, очистки списка и импорта с заменой появляется уведомление с кнопкой «↶ Отменить» (или клавиша U). Всё возвращается как было.
- Подтверждения говорят, что именно пропадёт: «Удалить колоду „English → Русский“ (14 сл.)…», «Сейчас в библиотеке колод: 2, слов: 30. В файле колод: 1, слов: 5…». Если библиотека пуста, импорт ничего не спрашивает: терять нечего.
- Пустая библиотека объясняет первые три шага и предлагает демо-колоду или восстановление из файла. Вкладка теста подсказывает, что сначала нужна колода, и не даёт нажать неработающие кнопки.
- Импорт сохраняет дату создания колоды. Тот же файл можно выбрать повторно даже после «Отмена».

**Для разработки**
- Удалён мёртвый фоновый слой (`initFX`, `initParallax`, canvas, свечения, ~220 строк). Он не работал ещё на `main`.
- Проверка резервной копии вынесена в `learning.js` (`restoreBackup`) и покрыта тестами. Добавлены тесты на переключение языка и DOM-привязку i18n, а также на крайние случаи `/api/ai`.
- `npm run coverage`: покрытие Node-модулей с порогами (строки ≥ 95%, ветки ≥ 85%, функции ≥ 90%). Сейчас: строки 99–100%; ветки: `ai-core` 94%, `i18n` 84%, `learning` 91%, `api/ai` 99%.
- `npm run coverage:e2e`: покрытие кода в браузере по e2e-прогону. `app.js` 69% → 78% и список функций, которые ни разу не выполнились.

## v2.9 — безопасный серверный ИИ

**Для пользователя**
- Если ИИ не смог перевести слова, приложение говорит почему (например, «провайдер отклонил API-ключ» или «слишком много запросов») и сразу переводит бесплатным переводчиком.
- Слова, которые выглядят как команды («забудь инструкции и…»), просто переводятся как текст — модель их не выполняет.

**Для деплоя**
- `/api/ai` больше не пропускает произвольные запросы к модели. Он принимает только список слов и пару языков, промпт собирает сам сервер. Раньше через сайт с серверным ключом можно было бесплатно гонять любые запросы за счёт владельца.
- Принимаются только `POST`-запросы с самого сайта (или с доменов из `ALLOWED_ORIGINS`). Есть лимит запросов по IP, ограничения на размер и длину слов.
- Ключ больше никогда не попадает в ответы и логи: ошибки провайдера приходят клиенту только кодом (`provider-auth`, `provider-timeout`…).
- Свой ключ пользователя можно отправить только известным провайдерам (OpenAI, Groq, OpenRouter, DeepSeek, Mistral, Together, Gemini) по HTTPS. Остальные хосты добавляются через `AI_ALLOWED_HOSTS`.
- ⚠️ Контракт API изменился — см. [DEPLOY.md](DEPLOY.md), раздел «Старые клиенты».

## v2.8 — надёжность и автотесты

**Для пользователя**
- Испорченный файл резервной копии больше не ломает импорт: появляется понятное сообщение, библиотека остаётся как была.
- Восстановление из резервной копии теперь точное — ни одно поле не меняется.
- Если память браузера заполнена, приложение само чистит кэш переводов. Если и это не помогло, один раз предупреждает и советует скачать копию; прогресс в открытой вкладке не теряется.
- Если переводчик не отвечает, тренировка начинается с уже переведёнными словами, а остальные ждут в библиотеке и догружаются позже. Приложение больше не висит по 16 секунд на каждом слове.
- Важные предупреждения больше не перекрываются обычными всплывающими сообщениями.

**Для деплоя и разработки**
- `npm run dev` поднимает локальный сервер, который ведёт себя как Vercel: отдаёт статику и запускает настоящую функцию `/api/ai`. Старый `serve` отдавал наружу даже `.git/config`.
- `npm run test:e2e` — сквозные сценарии в настоящем браузере: офлайн, резервные копии, сбои API, переполнение памяти, языки.
- Lighthouse Best Practices: 96 → 100.

## v2.7 — умные повторения, доступность, скорость

**Для пользователя**
- После переворота карточки есть четыре оценки: «Не вспомнил» (1), «Трудно» (3), «Запомнил» (2), «Легко» (4). Интервалы считаются по алгоритму SM-2: лёгкие слова уходят далеко, трудные возвращаются раньше. Старый прогресс переносится автоматически.
- В режиме ввода правильный ответ после подсказки считается «трудно».
- Слова, добавленные без интернета, переведутся сами, когда сеть вернётся.
- Текст в светлой теме стал контрастнее, карточку удобнее проходить с клавиатуры и экранным диктором.
- На слабых телефонах 3D-анимации по умолчанию выключены (кнопка «3D» включает их).
- Сайт быстрее открывается на телефонах: Lighthouse Performance 52 → примерно 86–94 (на этой машине замеры заметно шумят).

**Для деплоя**
- Ничего настраивать не нужно.
