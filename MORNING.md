# Доброе утро! Что сделано за ночь

Всё лежит на ветке **`feat/sm2-a11y-perf`**: 12 коммитов поверх `main`, версии с v2.7 по v2.14. Ничего не влито в `main` и не отправлено на GitHub — это решаешь ты (см. конец файла).

## Что появилось, по версиям

- **v2.7** — умные повторения (алгоритм SM-2): после переворота карточки четыре оценки — «не вспомнил / трудно / запомнил / легко». Текст стал контрастнее, сайт заметно быстрее открывается на телефоне.
- **v2.8** — понятные сообщения, когда что-то идёт не так: битый файл копии, переполненная память браузера, не отвечает переводчик. Данные при этом не теряются. Появились автотесты в настоящем браузере.
- **v2.9** — серверный ИИ (`/api/ai`) защищён: принимает только перевод списка слов и только с нашего сайта, есть лимит запросов, ключ никогда не показывается.
- **v2.10** — после удаления колоды или слова, очистки списка и импорта можно нажать «↶ Отменить». Пустая библиотека объясняет, с чего начать.
- **v2.11** — строгая защита страницы (CSP и другие заголовки). Шрифты теперь грузятся с нашего сайта, а не с Google.
- **v2.12** — русские заголовки набраны настоящим шрифтом с засечками (Literata) вместо запасного Georgia. По снимкам экранов исправлено шесть мелких поломок вёрстки.
- **v2.13** — новая вкладка **«Прогресс»**: сколько слов повторять сегодня и на 7/30 дней вперёд, точность за месяц, насколько прочно держатся слова, самые трудные слова с кнопкой «Потренировать».
- **v2.14** — **поделиться колодой**: ссылка, QR-код или файл. Друг видит превью и добавляет слова к себе. Прогресс не передаётся, а сама колода в ссылке не проходит через сервер.

## Какие дыры и баги закрыты

- **Открытый прокси.** Раньше через `/api/ai` с серверным ключом кто угодно мог гонять любые запросы к ИИ за твой счёт. Теперь принимается только перевод слов, промпт собирает сервер, запросы с чужих сайтов отклоняются, есть лимит по IP.
- **Утечка ключа в ошибках.** Ошибки провайдера вроде «Incorrect API key: sk-…» больше не уходят в браузер и не пишутся в логи.
- **`__proto__` как язык.** Импорт резервной копии и ссылки на колоду принимали `__proto__` как «язык». Исправлено и покрыто тестами.
- **XSS.** Слова вида `<img src=x onerror=…>` из копии, ссылки или ответа ИИ везде показываются простым текстом. Это проверяют тесты на уровне DOM, а строгая CSP служит вторым слоем защиты.
- **Prompt injection.** Слова передаются модели отдельно от инструкций, а «лишние» слова в ответе модели отбрасываются.
- **Лишние шрифты при старте.** Названия языков «Azərbaycanca» и «Қазақша» в выпадающих списках заставляли браузер скачивать ещё ~110 КБ шрифтов. Исправлено сегодня утром.

## Скорость

Сравнение v2.8 и v2.14 в одинаковых условиях (Lighthouse, мобильный профиль, по 5 прогонов каждой версии, чередуя, сжатие как на Vercel): Performance **76 → 75** по медиане, вес страницы **438 → 436 КБ**. Accessibility и Best Practices — 100. Шрифты, «Прогресс» и QR скорость не ухудшили: QR и анимации грузятся только когда нужны. Замеры на этом компьютере сильно шумят, отдельные прогоны дают от 50 до 96, поэтому смотри на медианы.

## Перед деплоем

Подробно — в [DEPLOY.md](DEPLOY.md). Коротко:

1. **Переменные окружения на Vercel.** Все необязательные, без них работает бесплатный переводчик:
   - `OPENAI_API_KEY` — серверный ключ: ИИ для всех посетителей за твой счёт;
   - `OPENAI_BASE_URL`, `OPENAI_MODEL` — провайдер и модель для этого ключа;
   - `ALLOWED_ORIGINS` — нужна, только если API будет вызывать другой твой сайт. Свой домен разрешён всегда.
2. **Защитить ключ от перерасхода:** правило Rate Limit в Vercel Firewall для `/api/ai` и месячный лимит расходов у провайдера. Встроенный лимит живёт в памяти одного сервера — это лишь первый барьер.
3. **CSP** задана в `vercel.json`, делать ничего не нужно. Если поменять маленький встроенный скрипт в `<head>`, `npm test` покажет новый хеш — его надо вписать в `vercel.json`.
4. **Откат:** Vercel → Deployments → предыдущий деплой → «Instant Rollback».

## Проверка руками за 5 минут

```bash
npm install
npm run dev
```

Открой http://localhost:3000 и пройди по списку:

- [ ] «Демо-колода» → переверни карточку (пробел) → оцени клавишами 1–4. Внизу появилась «↶ Отменить» — нажми её.
- [ ] Вкладка **«Прогресс»**: видны прогноз, точность и трудные слова. Нажми «Потренировать».
- [ ] **«Моя библиотека»** → у колоды «Поделиться» → «Копировать». Открой ссылку в приватном окне: превью → «Добавить».
- [ ] Удали слово в списке колоды и нажми «Отменить» в уведомлении.
- [ ] Переключи язык 🌐 RU / EN / UZ и тему ◐. Всё переведено и читается.
- [ ] Сузь окно до ширины телефона: ничего не вылезает за край.
- [ ] DevTools → Console: нет красных строк «Refused to… / Content Security Policy».

Автоматические проверки, запускать по одной:

```bash
npm test
```

```bash
npm run test:e2e
```

```bash
npm run test:browser
```

```bash
npm run screens
```

Для `test:e2e`, `test:browser` и `screens` один раз нужен `npx playwright install chromium`. Снимки экранов появятся в `test/screens/`.

## Что решаешь ты

1. **Влить ветку в `main` и отправить на GitHub.** Ветка `feat/sm2-a11y-perf` проверена целиком: все наборы тестов зелёные.
2. **Деплой на Vercel** и нужен ли серверный ключ ИИ (если да — сразу с лимитами из пункта «Перед деплоем»).

   - списки выбора языка теперь в системном шрифте (Segoe UI на Windows) — так меньше грузится при старте.
